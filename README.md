# Node.js Backend Development

Companion repository for **Node.js Backend Development: A Practical Guide to Building Production-Ready APIs** by **Yasin Besni**.

This repository contains selected runnable examples, practical exercises, and supporting notes for developers learning backend development with Node.js, Express, MongoDB, and REST APIs.

> **Want the complete step-by-step guide?**  
> The book explains the reasoning behind these examples and connects them into a structured backend learning path.
>
> **Read the book on Amazon:** https://www.amazon.com/dp/B0HL1NWT4B

## Who This Is For

This repository is useful if you are:

- learning Node.js backend development
- building your first Express API
- trying to understand middleware and error handling
- learning how to separate routes and controllers
- moving from small examples toward a cleaner backend structure

## Start Here

If you are new to the project, begin with:

1. `02-express-basics/` — run a minimal Express API
2. `03-routing-and-controllers/` — separate route definitions from request logic
3. `04-middleware/` — understand middleware flow and order
4. `05-error-handling/` — centralize API errors

Each example can be run independently.

## Repository Structure

- `01-node-http-basics/` — Node.js HTTP fundamentals
- `02-express-basics/` — Express application basics
- `03-routing-and-controllers/` — Separating routes and controller logic
- `04-middleware/` — Request/response flow and middleware
- `05-error-handling/` — Centralized error handling patterns
- `06-mongodb-mongoose/` — MongoDB and Mongoose fundamentals
- `07-rest-api-example/` — A practical REST API example

## How to Use This Repository

Each folder focuses on one backend concept. Start with the earlier sections if you are new to Node.js backend development, or jump directly to the topic you want to review.

The repository is intentionally practical: the examples are small enough to understand, but structured so they can grow into larger applications.
