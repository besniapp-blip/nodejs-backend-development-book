# Node.js Backend Development

Companion repository for **Node.js Backend Development: A Practical Guide to Building Production-Ready APIs** by **Yasin Besni**.

This repository contains selected code examples, practical exercises, and supporting notes for developers learning backend development with Node.js, Express, MongoDB, and REST APIs.

## About the Book

The book follows a practical, step-by-step approach to backend development, focusing on understanding how the pieces of a real API fit together rather than only showing isolated snippets.

**Amazon:** https://www.amazon.com/dp/B0HL1NWT4B

## Repository Structure

- `01-node-http-basics/` — Node.js HTTP fundamentals
- `02-express-basics/` — Express application basics
- `03-routing-and-controllers/` — Separating routes and controller logic
- `04-middleware/` — Request/response flow and middleware
- `05-error-handling/` — Centralized error handling patterns
- `06-mongodb-mongoose/` — MongoDB and Mongoose fundamentals
- `07-rest-api-example/` — A practical REST API example

## How to Use This Repository

Each folder is designed to focus on one backend concept. Start with the earlier sections if you are new to Node.js backend development, or jump directly to the topic you want to review.

The examples in this repository are companion material. The full explanations, reasoning, and step-by-step progression are available in the book.
